# lipsalinCreations Business Website

A responsive, single-page business website for the lipsalinCreations creative music brand.

## Included
- `index.html` — website content and sections
- `style.css` — responsive dark-and-gold design
- `script.js` — mobile navigation and automatic copyright year

## Publish with GitHub Pages
1. Extract this ZIP file on your computer.
2. Open your GitHub repository.
3. Upload `index.html`, `style.css`, and `script.js` to the repository's top-level/root folder (not inside another folder).
4. Commit the changes to the `main` branch.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for the deployment to finish. Your site address will appear in Settings → Pages.

## Customize
The YouTube links currently point to https://www.youtube.com/@lipsalincreations.
Replace that URL in `index.html` if your channel address changes. Add your business email or phone number in the Contact section when you are ready to publish them.
